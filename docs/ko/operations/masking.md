# 마스킹과 데이터 보관

SADE의 분석 결과와 원격 로그 캐시는 **다른 저장 경로**입니다. 화면의 값이 가려져 있다는 이유로 DB 전체에 원문이 없다고 판단하면 안 됩니다.

## 저장 범위

| 자료 | 현재 처리 |
|---|---|
| 분석 결과의 헤더·본문 값 | 스칼라 원문을 가리고 구조·자료형·탐지 근거를 보존 |
| 호출 기록 | 최근 최대 200건. 쿼리 값·원래 요청 ID·client IP 제거 |
| API 샘플 | API당 최대 3건의 제한된 구조·마스킹 샘플 |
| 민감정보 관측·검사 | 위치·유형·상태·룰 버전·근거 참조. 원문 값 없음 |
| Splunk 증분 증거 | `source_evidence`에 소스당 최근 최대 10 MB. **원문 값 포함 가능** |
| WebHDFS 원문 | worker 메모리에서 처리. 재분류 때 자료가 없으면 재수집 필요 |
| 연결 인증 토큰 | 서버의 별도 비밀 저장 영역. 화면 모델·Export에서 제외 |
| 명세·코드 인벤토리·설정·이력 | 작업과 비교에 필요한 자료 보관 |

## 화면의 값과 상태

`<string>`, `<number>` 같은 표시는 실제 호출 원문이 아니라 가려진 자료형입니다. 명세의 Example은 선언된 예시일 수 있습니다. NULL / EMPTY / MASKED / REDACTED / UNKNOWN을 실제 값 PRESENT와 구분합니다.

마스킹된 값도 명확한 필드 의미가 있으면 유형 후보가 될 수 있지만, 원문 형식 검증을 통과했다는 Value matched를 새로 만들지는 않습니다.

## 재분류와 과거 이력

룰 변경은 저장된 자료를 다시 분류하며 과거 스캔 기록이나 과거 DB·백업 원문을 소급 삭제하지 않습니다. Splunk 캐시는 크기 제한이 있으므로 모든 과거 로그를 재현하는 보관소가 아닙니다.

연결 해제는 등록과 연결 상태를 정리합니다. 원본 로그·명세 파일과 과거 Scan 이력을 모두 삭제하는 기능으로 보아서는 안 됩니다.

## 운영 시 결정할 사항

현재 자동 보관 기간·만료 삭제 정책은 제공하지 않습니다. DB·백업·입력 로그·인증 토큰의 접근과 보관 기간을 별도로 정하고, 민감한 실제 데이터 대신 합성 데이터로 먼저 검증하세요.
