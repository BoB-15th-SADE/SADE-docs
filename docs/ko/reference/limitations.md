# 지원 범위와 제한

현재 구현의 범위입니다. 동작하지 않는 기능을 로드맵만으로 지원한다고 표시하지 않습니다.

## 데이터와 연동

| 항목 | 현재 범위 |
|---|---|
| 원격 로그 | Splunk Search REST API, Cloudera WebHDFS의 JSON HTTP 이벤트 |
| 명세 | OpenAPI 3.0 / 3.1 JSON. 업로드 최대 10 MB |
| 원격 읽기 | 소스당 한 번 최대 10 MB, HTTP 요청 대기 90초 |
| 로그 UI | Splunk·Cloudera 연결 제공. S3·Elasticsearch 직접 연결 미제공 |
| 로컬 파서 | CLI/기존 등록으로 HTTP·identity 형식 일부 유지. 원격 identity 프로필은 미제공 |
| Cloudera 검증 | 모의 WebHDFS 흐름 검증. 실제 기업 서버 검증은 별도 |
| 대용량 수집 | 완전한 페이지 수집·장기 로그 아카이브 기능 아님 |
| GitHub | 한 작업 최대 50개 저장소, 목록 최대 2,000개 |

## 분석 한계

- 기록하지 않은 본문·헤더, 수집 기간 밖의 호출은 판단할 수 없습니다.
- 이름·주소의 자유문장 NER, XML·바이너리·압축 해제 분석은 제공하지 않습니다.
- 기관별 계좌·운전면허·CI·DI 값 검증은 미지원이며 필드 의미 근거를 사용합니다.
- 지원 값 형식은 발급 여부·소유자·인증 성공·JWT 서명 검증과 다릅니다.
- HTTP REST를 대상으로 하며 gRPC·메시지 큐 관계는 분석하지 않습니다.
- 동적 HTTP 대상과 미지원 코드 라이브러리는 흐름에서 빠질 수 있습니다.
- 두 명세 점검은 전체 보안 진단·권한 검증·규정 준수 검증이 아닙니다.

## 검사와 보관 한도

민감정보 기본 한도는 본문 1 MiB, 깊이 32, 배열 10,000개, 문자열 16,384자, 위치별 필드 30,000개입니다. 초과·미지원·파싱 실패는 부분 검사 또는 검사 불가 사유를 남깁니다. 샘플 Test는 별도로 32 KiB 제한입니다.

화면 호출 기록은 최대 200건, API 샘플은 최대 3건입니다. Splunk의 최근 원문 증거 캐시는 소스당 최대 10 MB이며 무기한 재현 가능한 전체 이력이 아닙니다.

내장 SSO·서버 사용자 인증·조직별 RBAC·Slack 알림·자동 데이터 보관 기간 설정은 없습니다. 민감정보의 제3자 제공 허용 여부나 법적 분류를 자동 확정하지 않습니다.
