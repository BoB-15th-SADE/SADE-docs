# 자주 묻는 질문

## 명세와 로그를 모두 등록해야 하나요?

아닙니다. 명세·코드만으로 선언 API와 민감 필드 후보를 볼 수 있고 로그만으로도 인벤토리를 만들 수 있습니다. 실제 값 관측과 명세 준수 비교에는 각각 필요한 근거가 있어야 합니다.

## Scan 전에 Sync를 해야 하나요?

Run scan에 로그 수집이 포함되므로 필수는 아닙니다. Sync는 수집 상태만 확인하거나 특정 소스를 가져올 때 사용합니다. [작업 구분](../operations/scans.md)을 확인하세요.

## 룰 수정은 전체에 적용되나요?

All APIs 범위의 공통 룰은 전체 대상에 적용합니다. 특정 API·위치를 지정한 룰은 그 범위에만 적용합니다. 저장 후 자동 재분류하며 과거 스캔 이력을 덮어쓰지 않습니다.

## 오탐 결과를 어떻게 조정하나요?

Data Types에서 별칭·경로·값 조건을 수정하거나 비활성화합니다. 사용자 룰은 삭제할 수 있고, 제한된 예외는 사유·만료일을 가진 Exclusion으로 관리합니다. 현재 가이드는 결과 행을 임의 편집하는 기능을 전제로 하지 않습니다.

## 민감정보가 발견되면 위반인가요?

아닙니다. 정보 유형·근거 분류입니다. Field matched, Value matched, 접근 범위, 실제 전송과 정책 위반은 서로 다른 판단입니다.

## 체크가 없으면 안전한가요?

미수집·미지원·미평가일 수 있습니다. 검사 상태와 이유를 확인하세요. 코드나 명세의 선언은 실제 값 검증과 다릅니다.

## 원문 개인정보를 저장하지 않나요?

분석 결과는 가리지만 Splunk 증거 캐시는 원문을 포함할 수 있습니다. 예전 DB·백업까지 소급 정리하지 않습니다. [저장 범위](../operations/masking.md)를 확인하세요.

## Slack 알림·SSO·조직별 권한이 있나요?

현재 프로젝트에는 해당 기능이 구현되어 있지 않습니다. 이 문서는 현재 동작하는 기능을 기준으로 구성합니다.
