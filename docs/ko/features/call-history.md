# 호출 기록

**APIs → Call History**에서 저장된 최근 요청·응답 기록을 검색합니다. 로그 저장소 전체를 실시간 조회하는 화면은 아닙니다.

## 빠른 확인

1. Run scan이 완료되었는지 확인합니다.
2. Call History에서 경로·메서드 검색이나 상태 코드 필터를 사용합니다.
3. 호출을 선택해 요청·응답의 수집 상태, 구조, 명세 차이를 봅니다.
4. 필요한 경우 해당 API 상세로 이동합니다.

| 항목 | 읽는 방법 |
|---|---|
| 요청 시각·메서드·경로·상태 | 수집된 호출 메타데이터 |
| 헤더·본문 | 수집된 경우 구조·마스킹 표시, 미수집이면 미수집 상태 |
| 명세 차이 | 해당 호출과 명세 비교에서 확인한 차이 |
| 출처 | 로그 연결 또는 증거 참조 |

## 보관 범위

현재 대시보드의 호출 목록은 최근 **최대 200건**으로 제한됩니다. 화면은 이 저장된 목록을 페이지 단위로 읽으며, 페이지를 넘겨도 원본 전체 로그를 검색하지 않습니다. 집계 호출 수가 목록의 행 수보다 많을 수 있습니다.

새 분석 결과의 본문·헤더 스칼라 값은 가리고, 쿼리 값·원래 요청 ID·client IP는 결과에서 제거합니다. Flows의 호출자 집계 표시는 별도 분석 결과이므로 원문 로그가 모두 사라졌다는 의미는 아닙니다. [저장 범위](../operations/masking.md)를 확인하세요.

본문이 없으면 필드가 없다고 판단하지 않습니다. 최신 호출이 보이지 않으면 수집 범위, 매핑과 마지막 스캔 상태를 확인합니다.
