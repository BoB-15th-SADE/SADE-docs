# 결과 보고하기

SADE 결과를 경영진, 개발 팀, 감사 담당에게 전할 때 쓰는 방법입니다. 같은 결과라도 받는 사람마다 필요한 부분이 다릅니다.

## 1. 보고 전에 범위 확인

결과는 연결한 자료와 분석한 기간 안에서만 맞습니다. 보고서 첫머리에 아래를 적습니다.

| 적을 것 | 확인하는 곳 |
|---|---|
| 분석이 끝난 시각 | Overview 위쪽 |
| 로그 기간 | API 상세 Management 탭의 Data used(분석한 로그 기간) |
| 연결한 자료 | 코드 저장소, 등록한 명세 서비스, 로그 소스 목록 |
| 미평가 API 수 | Overview의 Management Priority |
| 빠진 자료 | Connect 화면 위쪽의 "우선순위 판단에 빠진 자료" 표 |

미평가가 많으면 등급 분포보다 "무엇을 더 연결해야 하는지"를 먼저 보고합니다.

## 2. 엑셀로 내보내기

Inventory에서 필터를 건 상태로 Export to Excel(엑셀 내려받기)을 누릅니다.

| 시트 | 내용 | 쓰는 곳 |
|---|---|---|
| Summary | 등급별 API 수, 빠진 자료 | 경영진 보고 첫 장 |
| P1 ~ 미평가 | 등급별 API 목록. 줄마다 출처, 판정 이유, 더 높아질 수 있는 등급, 빠진 자료 | 개발 팀 전달, 조치 추적 |

- 화면이 한국어면 엑셀도 한국어로 나옵니다.
- 요청, 응답 본문의 값은 들어가지 않습니다.
- 다음 점검 때 같은 필터로 다시 내려받아 등급 변화를 비교합니다.

## 3. 받는 사람별로 전하기

| 받는 사람 | 전할 것 | 함께 붙일 것 |
|---|---|---|
| 경영진 | P1, P2 수, 외부에 노출된 민감 API 수, 관리 대장에 없는 API(Shadow) 수 | 미평가 비율과 다음 점검까지 채울 자료 |
| 개발 팀 | 담당 API 목록과 등급별 판정 이유 | API 상세의 핸들러 위치, CODEOWNERS 담당 후보 |
| 감사, 컴플라이언스 | 점검 범위, 방법, 한계 | [보안 검토 자료](../getting-started/security-review.md), [지원 범위와 제한](../reference/limitations.md) |

## 4. 등급을 한 문장으로 설명하기

등급은 신호의 조합으로 정해집니다. 아래 틀로 설명하면 근거가 함께 전달됩니다.

```text
<API>는 <확인된 신호>가 확인되어 <등급>입니다.
<모르는 신호>가 확인되면 <더 높은 등급>이 될 수 있습니다.
```

예시

| 등급 | 문장 |
|---|---|
| P1 | `POST /api/payments`는 외부 HTTP 구간에서 카드번호 전달이 관측되어 P1입니다. |
| P2 | `PUT /api/members/me`는 이메일, 전화번호를 다루고 외부 주소에서 호출되어 P2입니다. 외부 HTTP 구간 관측이 확인되면 P1이 될 수 있습니다. |
| P2 | `DELETE /api/orders/{id}`는 공개 접근에 인증 없이 허용된 변경 API라 P2입니다. |
| P3 | `GET /api/payments/admin/export`는 코드와 명세에 없고 로그에서만 보여 P3입니다. 민감정보나 외부 접근이 확인되면 올라갈 수 있습니다. |
| 미평가 | `GET /api/items`는 판단할 근거가 없어 미평가입니다. 로그의 출발지 IP와 본문을 연결하면 판정할 수 있습니다. |

신호별 판단과 근거는 [API 상세](api-details.md)의 Management 탭에 있습니다. 예시의 API와 값은 가상입니다.

## 5. 보고할 때 피할 표현

| 피할 표현 | 이유 | 바꿔 쓸 표현 |
|---|---|---|
| "P4는 안전합니다" | P4는 관련 평가에서 신호가 없다는 뜻입니다 | "P4는 수집한 자료에서 검토 신호가 없었습니다" |
| "취약점 n개 발견" | SADE는 취약점을 판정하지 않습니다 | "먼저 검토할 API n개" |
| "인증이 적용돼 있습니다" | 코드와 명세의 선언만 읽습니다 | "인증이 선언돼 있습니다" |
| "민감정보가 전송됩니다" | 민감 라벨은 분류 결과입니다 | "민감 유형이 확인된 API입니다" |
| "전체 API는 n개입니다" | 수집한 범위의 수입니다 | "분석 기간에 확인한 API는 n개입니다" |
